[Live Demo](https://lyceum-ten.vercel.app/)

### Finitio

An interactive university mathematics platform built around visual explanations and reusable mathematical components. Its first courses cover Bayes' Theorem and Linear Transformations.

`Django` · `React` · `PostgreSQL`

[Live Demo](https://finitio.vercel.app/)

### NASA Turbofan Predictive Maintenance

A machine-learning project using the NASA C-MAPSS simulated turbofan dataset to study predictive maintenance and imminent-failure detection.

The project compares Logistic Regression, Random Forest, and XGBoost, incorporating cross-validation and cost-sensitive decision thresholding.

`Python` · `scikit-learn` · `XGBoost` · `Pandas` · `NumPy`

[Repository](https://github.com/Pabo-0/nasa-turbofan-predictive-maintenance)
